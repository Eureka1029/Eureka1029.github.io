# Theme source

The files in `themes/PaperMod` are the unmodified runtime assets, layouts, translations, theme metadata, and MIT license from [PaperMod at commit `1181196`](https://github.com/adityatelange/hugo-PaperMod/tree/118119693d8b5ac211b939775678310973bcb232).

Site configuration and content live in `hugo.yaml` and `content/`. When updating PaperMod, replace the runtime files with those from the new upstream revision and run the production build and link check described in the README.
